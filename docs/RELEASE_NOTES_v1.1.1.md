# Field Validation Plugin v1.1.1

修正リリースです。設定内容の移行や再設定は不要です。プラグインを更新するだけで適用されます。

## 修正

- 「空欄である」「空欄ではない」の条件が正しく判定されない問題を修正しました。v1.1.0 では、この条件を使ったチェックが常にエラーになる、または適用条件として成立しない状態になっていました。
- 設定後に対象フィールドがアプリのフォームから削除されると、レコードを保存できなくなることがある問題を修正しました。存在しないフィールドに対するチェックはスキップされ、同じルール内のほかのチェックはこれまでどおり行われます。
- 現在利用できないフィールドや条件を含む既存の設定を、設定画面を開いて保存しただけで意図せず書き換えてしまう問題を修正しました。該当する設定は「現在使用できないフィールド」「現在使用できない設定」と表示され、内容はそのまま保持されます。

## 変更

- kintone の仕様上、レコード保存時に正しく判定できない添付ファイルフィールドを、新規の入力チェック設定の対象外としました。設定画面のフィールド候補に表示されなくなります。
- 添付ファイルフィールドを含む既存の設定は保持されますが、レコード保存時には該当するチェック（ファイルあり／なし、ファイル名の条件）をスキップします。適用条件（IF）に添付ファイルの条件が含まれるルールは、適用するかどうかを判断できないため、そのルール全体をスキップします。
- テーブル内のフィールドは本プラグインのチェック対象外のため、新しく条件を設定するときのフィールド候補に表示されなくなりました。すでに保存されている設定は削除されず、そのまま残ります。

## その他

- 動作を検証する回帰テストを追加しました。

## 注意

- 存在しないフィールドや添付ファイルフィールドを対象にしたチェックをスキップした場合、ブラウザの開発者ツール（Console）に警告を出力します。該当するルールは設定画面で見直してください。
