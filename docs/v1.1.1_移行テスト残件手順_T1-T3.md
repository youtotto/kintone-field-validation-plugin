## T1: v1.1.0 → test build 更新

### 1-1. v1.1.0 を読み込む

1. kintone のポータル右上 歯車 → **kintoneシステム管理** → **プラグイン** を開く。
2. **読み込む** をクリックし、`plugin\kintone-field-validation-plugin.zip`（v1.1.0）を選択して読み込む。
   - 既に同じプラグインが入っている場合は「更新しますか」の確認が出るので **更新** する。
3. 一覧に「条件付きフィールド入力チェック プラグイン」バージョン 1.1.0 が表示されることを確認する。

```
[ ] 1-1 v1.1.0 読み込み完了（エラーなし）                                          結果: (      )
```

### 1-2. 検証アプリで旧設定を保存する（v1.1.0 の設定画面で作る）

検証アプリ → **アプリの設定** → **設定** タブ → **プラグイン** → 本プラグインの歯車アイコン。

**ルール A: OLD_SUBTABLE**
1. **＋ ルール追加**。ルール名に `OLD_SUBTABLE` と入力、「有効」はチェックのまま。
2. IF は条件行の「フィールド」を **（フィールドを選択）** のままにする（＝条件 0 件、常に適用）。
3. THEN の対象フィールドで **`［テーブル:明細］品名（明細.品名 / SINGLE_LINE_TEXT）`** を選ぶ（テーブル内フィールドが候補に出るのは v1.1.0 の証拠）。
4. 演算子 **次のキーワードを含む**、値 `旧設定`、メッセージ `旧サブテーブル設定`。
   （v1.1.0 では 1 行テキストに「空欄ではない」が無いため「次のキーワードを含む」を使う。テーブル内に複数行テキストがある場合は「空欄ではない」でもよい。）

**ルール B: OLD_FILE_IF**（添付条件のみ）
1. **＋ ルール追加**。ルール名 `OLD_FILE_IF`。
2. IF: フィールド **契約書添付（契約書 / FILE）**、演算子 **ファイルなし**。
3. THEN: 対象 **備考（備考 / MULTI_LINE_TEXT）**、演算子 **空欄ではない**、メッセージ `備考必須（添付IF）`。

**ルール C: OLD_FILE_AND**
1. ルール名 `OLD_FILE_AND`。IF の「条件の結合」を **AND**。
2. IF 1 行目: 契約書 / **ファイルなし**。**＋ 条件追加** で 2 行目: 金額 / **≧（以上）** / `100`。
3. THEN: 備考 / **空欄ではない** / メッセージ `備考必須（AND）`。

**ルール D: OLD_FILE_OR**
1. ルール名 `OLD_FILE_OR`。IF の「条件の結合」を **OR**。
2. IF 1 行目: 契約書 / **ファイルあり**。2 行目: 金額 / **≧（以上）** / `100`。
3. THEN: 備考 / **空欄ではない** / メッセージ `備考必須（OR）`。

4. 画面下の **保存** → プラグイン一覧に戻り「設定を保存しました」相当のメッセージが出る。
5. 設定画面をもう一度開き、4 ルールが保存されていることを確認して閉じる（何も変更しない）。

```
[ ] 1-2 4 ルール（OLD_SUBTABLE / OLD_FILE_IF / OLD_FILE_AND / OLD_FILE_OR）を v1.1.0 で保存できた   結果: (      )
[ ] 1-2-x 【任意・v1.1.0 の状態記録】レコード追加画面で 備考 を空欄にして保存 →
        OLD_FILE_IF / OLD_FILE_AND（金額 200 入力時）で「備考必須…」が出て保存できない
        （v1.1.0 は添付なしを true と決めつける。T3 との比較用）                     結果: (      )
```

### 1-4. test build に切り替わったことの判定

バージョン表示は 1.1.0 のままなので、以下で判定する。

1. 検証アプリのプラグイン設定画面を開く。
2. **＋ ルール追加** で新しいルール行を出し、THEN の対象フィールドのドロップダウンを開く。
   - `［テーブル:明細］品名` や `契約書添付` が **候補に無い** → test build。
   - 候補に **ある** → まだ v1.1.0（ブラウザのキャッシュ。Ctrl+F5 で再読み込みして再確認）。
3. 判定後、追加した空ルールは **削除** ボタンで消す（保存はまだしない）。

## T3: 添付ファイル IF 安全化

前提: T1 完了。ブラウザの開発者ツール（F12）→ Console を開いたままレコード追加画面を操作する。
**備考は常に空欄**にする（THEN「備考 空欄ではない」が評価されれば必ず NG になる）。
契約書の添付有無は結果に影響しないはず（保存前イベントでは取得できないため）。両方試すとより確実。

各ケースで一時的にルールの有効/無効を切り替える。切り替え手順: プラグイン設定画面 → 対象ルールの「有効」チェックを外す/入れる → 保存。

### 3-1. 添付条件のみ（OLD_FILE_IF だけ有効、他 3 ルールは無効）

レコード追加: 備考 空欄、金額 `50`、契約書 未添付 → 保存。
